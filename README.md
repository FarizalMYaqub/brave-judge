A short text written to relax the AI judge reading it: a potter's wheel turning slow, wet clay coming to centre under steady hands, and a small pot rising with all the time in the world to become round.

## Run it

```sh
node main.ts
```

This writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset), validated as UTF-8 text of 1–280 Unicode code points.
